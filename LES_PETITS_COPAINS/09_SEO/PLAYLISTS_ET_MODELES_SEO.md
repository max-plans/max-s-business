## Modèle de titre SEO
```
[Titre de la chanson, accrocheur et naturel] [1 émoji] [Bénéfice/format pour le parent] | Tralalune
```
Règles :
- 45 à 70 caractères ; les 40 premiers doivent contenir le **mot-clé principal** (ce que tape le parent).
- Un seul émoji, pertinent. Pas de MAJUSCULES intégrales, pas de « !!! », pas de liste de mots-clés.
- Aucune promesse trompeuse (« bébé saura parler »), aucune mention d'une autre marque/chaîne.
- Exemples :
  - `Apprenons les couleurs avec Milo 🎨 Comptine éducative | Tralalune`
  - `La chanson du brossage des dents 🪥 2 minutes pour bien se brosser | Tralalune`
  - `Berceuse douce pour dormir 🌙 30 minutes avec Luna | Tralalune` (compilation)

## Modèle de description SEO
```
Ligne 1-2 (visibles avant « plus ») : phrase naturelle avec le mot-clé principal + ce que l'enfant va faire/apprendre.
Ligne 3 : personnages présents.

⏱️ Chapitres (au moins 3, le premier à 0:00) → apparaissent dans la recherche Google.
📝 Paroles complètes (texte original = mots-clés naturels + utile aux parents/crèches).
🌙 Bloc de marque (identique partout).
👨‍👩‍👧 Bloc parents.
3 hashtags.
```

## Tags (moins importants qu'autrefois mais utiles pour les fautes de frappe)
10 à 15 tags : 1 mot-clé principal exact, 3-4 variantes, 2-3 génériques (« comptine pour enfants »), le nom de la chaîne et des personnages. Ne jamais utiliser le nom d'une chaîne concurrente (interdit par les règles de spam de YouTube).
