# Bande-annonce de la chaîne (55 s, 1920×1080, 25 i/s)

- `bande_annonce_Tralalune_1080p.mp4` : vidéo finale (personnages animés, bulles de dialogue, vitrine des comptines, musique instrumentale originale, son normalisé à -14 LUFS).
- `image_bande_annonce.jpg` : image de la scène finale.
- `sous_titres_repliques.srt` : répliques horodatées = **script pour enregistrer les voix** des personnages plus tard (ElevenLabs avec les voix fixes de la chaîne). La version actuelle n'a pas de voix : les répliques sont dans les bulles.
- Régénérer : `python3 _outils/bande_annonce.py`

Mise en ligne : YouTube Studio → Personnalisation → Disposition → « Bande-annonce de la chaîne pour les visiteurs non abonnés ». Déclarer la vidéo « conçue pour les enfants ».
